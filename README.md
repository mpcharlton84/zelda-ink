Hello there !

This here is Zelda: Ink to the past, a project I developed by myself during the month of october 2025.
The objective was to recreate a small version of Zelda: A Link to the Past but hand-drawn, during the inktober event.

The web version of the game can be played [here](https://matthewpcharlton.com/games/zelda-ink/)  
A Windows version is available [here](https://matthewpcharlton.com/games/zelda-ink/ink.zip)  
An Android version is available [here](https://matthewpcharlton.com/games/zelda-ink/ink.apk)

You can find a dev diary and all sorts of other sillyness on my [bluesky](https://bsky.app/profile/teuvz.bsky.social)
